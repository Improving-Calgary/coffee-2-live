# AI Agent Instructions and Development Guidelines

Your primary goal is to write functional, high-quality, maintainable code that strictly adheres to the specifications and established project standards.

## Core Development Workflow

For any given task, you **must** follow this process:

1. **Synthesize Requirements:** If not provided, your primary instructions for the development task are contained within a spec file. You must start by thoroughly understanding all requirements and acceptance criteria outlined in the specifications.

2. **Follow Core Engineering Principles:** All code must adhere to the engineering principles established for this project.

3. **Meet the Definition of Done:** Your work is not complete until you have fulfilled every single item on the "Definition of Done" checklist. Before concluding your task, you **must** validate your work against this checklist.
